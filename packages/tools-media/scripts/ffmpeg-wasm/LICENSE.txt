NeoTools LGPL FFmpeg WASM core
==============================

This file is copied next to ffmpeg-core.js / ffmpeg-core.wasm after a successful
Docker build (packages/tools-media/Dockerfile.ffmpeg-lgpl).

The core is built WITHOUT --enable-gpl, WITHOUT libx264/libx265/libfdk/librubberband/libvidstab.

Not included (GPL / nonfree)
----------------------------
libx264, libx265, libfdk-aac, librubberband, libvidstab, libpostproc,
and FFmpeg filters that require --enable-gpl (hqdn3d, cropdetect, eq, …).

H.264 encode in the NeoTools browser UI uses WebCodecs + mp4-muxer (MIT), not this core.
